# Vending Machine Controller Using Verilog HDL

## Description

This project implements a vending machine controller using Verilog HDL based on a Finite State Machine (FSM). The controller accepts coins, tracks the inserted amount, compares it with the product price, and generates control signals to dispense the product or return change.

The design demonstrates the use of FSM concepts for controlling real-world digital systems.

## Features

- FSM-based architecture
- Supports coin input
- Tracks inserted money
- Compares amount with product price
- Generates product dispense signal
- Generates change output
- Reset functionality
